# MATRIX
MATRIX Public Release

# DESCRIPTION
This repository contains the simulation code related to the MATRIX Infrastructure.

# Release Notes
The MATRIX code developed is is subject to release approval from relevant Department of Defense agencies. Obtaining release approval is currently in progress, and the repository will be updated once approval is granted.

# USENIX Open Science
Following the open science policy, we are releasing artifacts
for MATRIX pending governmental approval by the relevant
Department of Defense agencies. While proprietary trained agents are with-
held due to intellectual property restrictions, the provided
infrastructure allows access to heuristic blue and red agents
and resources to train agents. We note that MATRIX reposi-
tory focuses on providing full access to simulation to enable
replication of unmodified agent training and evaluation. Run-
ning emulation evaluations requires direct access to hosted
enclaves, which cannot be annonymized for review. Once ac-
cepted, researchers can contact the authors to request access.
